# Cleaning Quote Request Assistant

Build a quote intake workflow for a small cleaning company and learn to set it up, test it, and troubleshoot it independently. The first commercial offer is a small paid pilot for one business.

## Product scope

- A customer submits one n8n form. The workflow records the request in one Google spreadsheet before it tries to create a draft.
- If details needed for a quote are missing, the workflow creates a follow-up draft in one Gmail inbox. If the required details are already present, the row is ready for the owner to quote. If a detail is uncertain, the owner can review it in the sheet.
- The owner reviews and sends any email, decides the price, and checks availability. The form confirms receipt. Pricing, calendar booking, and automatic sending are outside this version.
- Use fictional requests and a test inbox while building. Keep customer details and credentials out of project files, screenshots, and exports. Before using live data, agree with the owner on account access, what data to collect, and whether any request text can go to an AI provider.
- Track the roadmap, checklist, mentor instructions, and `.gitignore` in Git and publish them to a GitHub repository I control. Review staged changes before publishing.
